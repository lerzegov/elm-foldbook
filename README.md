# elm-foldbook
A multidimensional calc engine in elm used for teaching and research in corporate finance

## Credits
- the core calculation engine is Leonardo Taglialegne's [elm-interpreter](https://github.com/miniBill/elm-interpreter)
- the pivot table rendering is built on the base of [elm-pivot-table](https://github.com/integral424/elm-pivot-table)
